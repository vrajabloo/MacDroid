# Planned Features

The MVP architecture leaves room for the following features:

- Advanced keyboard and mouse mapping with live overlay editing
- Live gamepad event bridging using the new gamepad-ready profile fields
- Screen recording
- Macro recorder
- Multi-instance management
- Cloud save integration
- Custom Android image support
- Game artwork and icon extraction from APK metadata
- Play time tracking
- Per-game performance profiles
- Better APK install progress streaming
- Native fullscreen orchestration for emulator windows
